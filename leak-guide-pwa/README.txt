個人情報が漏れたら｜対処ガイド アプリ版(PWA)公開手順
=====================================================
このフォルダの中身を、そのまま「HTTPSで公開できる場所」に置いてください。
(ファイルを直接開く file:// では、インストールできません)

【含まれるファイル】
 index.html               ページ本体(メニューに「アプリとしてインストール」と、パスワード判定・生成・保管庫があります)
 manifest.webmanifest     アプリの設定(名前・アイコン・色)
 sw.js                    オフライン表示用の設定
 leak-hero.jpg            ヘッダー画像
 icons/                   アイコン画像(192・512・マスカブル・iPhone用180・ファビコン)

【置き方】
 すべて同じフォルダ(同じ階層)に置きます。サブフォルダに置く場合も、中身の相対関係は変えないでください。

【インストールのしかた】
 Android / PC(Chrome・Edge): メニューの「アプリとしてインストール」→ インストールの確認が直接出ます
 iPhone / iPad(Safari)    : メニューの「アプリとしてインストール」→ 手順が出ます(共有 → ホーム画面に追加)
 ※ LINE・Xなどのアプリ内ブラウザでは追加できません。SafariやChromeで開いてください。

【更新するとき】
 index.html などを差し替えたら、sw.js の先頭 'leak-guide-v3' の数字を上げて再公開してください。
 (数字を上げないと、古い画面が端末に残ることがあります)

【アイコンについて】
 アイコンは、アップロードいただいた正方形の画像を使っています。
 Androidの丸形アイコン用(maskable)は、文字が切れないよう、画像を80%に縮めて黒い背景に置いています。

【パスワード保管庫について】
 ・機関名とパスワードを、マスターパスワードで暗号化して、この端末のブラウザ内(ローカルストレージ)に保存します(最大20件)。
 ・マスターパスワードを忘れると復元できません。
 ・保存場所は、公開URLごと・ブラウザごとに別です。機種変更は、保管庫の「メールで送る」→ 新しい端末で「取り込む」を使います。
 ・重要な口座・主要メールのパスワードは、専用のパスワードマネージャーやパスキーをご利用ください。

【アイコンが古いまま・表示されないとき】
 ・以前のバージョンを追加済みの場合は、いったんホーム画面のアイコンを削除し、ブラウザで開き直してから、追加し直してください。
 ・icons フォルダと manifest.webmanifest が、index.html と同じ場所に置かれているか確認してください。
 ・ブラウザで https://(公開URL)/icons/icon-192.png を開いて、画像が表示されるか確認してください(表示されない場合は、置き場所が違います)。
